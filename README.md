# Personal Budget & Expense Tracker

## Project Description

This is a Personal Budget & Expense Tracker built using HTML and CSS.

The project is being developed step by step throughout the course. This Week 2 version builds on the HTML and CSS structure created in Week 1.

## Features

### Add Expense Form

The Add Expense section contains:

- Expense name input
- Expense amount input
- Category dropdown
- Add Expense button

The category dropdown contains five options:

- Food
- Transport
- Rent
- Entertainment
- Other

The button does not perform an action yet because JavaScript functionality will be added in a later week.

### Expense Table

The Your Expenses section contains a table with:

- Name
- Amount
- Category
- Date

The table currently contains five sample expenses.

### Multimedia

The page includes:

- A budget tracker icon
- An embedded YouTube budgeting video

### Interactive Elements

The page includes a collapsible "How to use this tracker" section using `<details>` and `<summary>`.

The table rows also have a hover effect.

The button uses `cursor: pointer`.

## CSS Selectors Used

The stylesheet demonstrates several CSS selectors and pseudo-classes:

- Element selectors
- ID selectors
- Class selectors
- Descendant selector
- Direct child selector
- `:nth-child()`
- `:hover`
- `:focus`
- `:not()`
