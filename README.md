
# 💰 My Budget Tracker

A simple and user-friendly Budget Tracker built with HTML and CSS. This project allows users to view expenses and provides a styled form for entering expense information.

This project was originally created in previous weeks and was visually improved during **Week 3** using CSS.

## 📌 Project Overview

The Budget Tracker is designed to provide a clean and organized way to display personal expenses.

The Week 3 focus was entirely on **visual design and CSS**, including:

* Color palette
* Typography
* Form styling
* Table styling
* CSS Box Model
* Card-based layout
* Responsive design

No new functionality was added during Week 3.

## 🎨 Color Palette

The project uses a consistent blue and neutral color palette.

| Purpose         | Color     |
| --------------- | --------- |
| Primary Button  | `#2563eb` |
| Dark Blue       | `#1e40af` |
| Headings        | `#172554` |
| Page Background | `#f1f5f9` |
| Card Background | `#ffffff` |
| Borders         | `#dbe3ef` |
| Table Header    | `#1e3a8a` |
| Table Hover     | `#dbeafe` |

The colors are applied consistently to headings, buttons, cards, table headers, borders, and other interface elements.

## ✍️ Typography

Google Fonts are used to improve readability and visual hierarchy.

### Poppins

Poppins is used for:

* Main heading
* Section headings
* Important text such as the "How to use" heading

### Inter

Inter is used for:

* Body text
* Labels
* Form inputs
* Buttons
* Table content

Using two complementary fonts creates a clear distinction between headings and normal content.

## 📝 Add Expense Form

The Add Expense form was improved with CSS styling.

The form includes:

* Styled labels
* Consistent input spacing
* Padding inside inputs
* Borders
* Rounded corners
* Focus effects
* Styled dropdown menu
* Professional button styling
* Button hover effect

The form is organized vertically to make it simple and easy to use.

## 📊 Expense Table

The expense table was redesigned to improve readability.

The table includes:

* Styled table headers
* Borders around cells
* Consistent cell padding
* Alternating row colors
* Row hover effects
* Rounded table appearance
* Clear visual separation between columns

The alternating row colors make individual expenses easier to read.

## 📦 CSS Box Model

The CSS Box Model was intentionally used throughout the application.

### Margin

Margins are used to create space between:

* The page header
* Add Expense section
* Expense table
* How To Use section
* Budgeting Tips section

### Padding

Padding is used inside:

* Cards
* Form inputs
* Buttons
* Table cells
* Details section

### Borders

Borders are used to:

* Define cards
* Separate table cells
* Style form inputs
* Improve visual structure

### Border Radius

Rounded corners are applied to:

* Cards
* Inputs
* Buttons
* Table
* Details section
* Video section

This gives the application a cleaner and more modern appearance.

## 🃏 Card-Based Layout

The following sections are displayed as distinct visual cards:

1. Page Header
2. Add Expense
3. Your Expenses

Additional sections such as the How To Use and Budgeting Tips areas also use the same visual style.

## 📱 Responsive Design

A CSS media query was added to improve the layout on smaller screens.

On smaller devices:

* Page spacing is reduced
* Headings become smaller
* Cards use less padding
* The expense table can scroll horizontally
* The layout remains readable and organized
